# PEX - Controle de Serviços

Projeto baseado na estrutura visual do arquivo original `Lista de Tarefas - Nova Opção Tecnologia`.

## Objetivo
Transformar a lista de tarefas em um sistema simples para registrar e acompanhar serviços de uma empresa de assistência técnica.

## Funcionalidades
- Cadastro de cliente
- Cadastro de equipamento
- Registro do problema/serviço
- Data de entrada
- Técnico responsável
- Status do atendimento
- Valor do serviço
- Observações
- Pesquisa por cliente ou equipamento
- Edição
- Exclusão
- Alteração de status
- Salvamento automático no navegador com LocalStorage

## Como executar
1. Abra o arquivo `index.html` no navegador.
2. O sistema funciona sem servidor e sem banco de dados.
3. Para publicar no GitHub Pages, envie `index.html` e `logo.png` (se possuir) para um repositório público e habilite Pages.

## Observação
Os dados ficam salvos no navegador utilizado. Para um sistema empresarial real, seria recomendado posteriormente utilizar banco de dados e autenticação.
